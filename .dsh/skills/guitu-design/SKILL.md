# 界面审美收敛（去 AI 味）

AI 味大多不是缺了什么，是多了什么。这一步**只删和改，不新增组件**。

取值和规则在项目根 `DESIGN.md`，先读。`DESIGN.md` 与 `css/style.css` 冲突时以实测为准，改 `DESIGN.md`。

## 顺序

1. 读 `DESIGN.md`（token、目标刻度、你的纠正记录）。
2. 跑体检，记下数字：`node tools/design-audit.js`（node 路径用 `load_workspace_dependencies` 取）。
3. 截图：桌面 1100–1280 宽、手机 390 宽各一张，按 `guitu-browser-test` 起 `http://localhost:9300`。**要跑浏览器的命令必须带 `sandbox_permissions: danger-full-access`**，否则 Edge 在沙箱里因命名管道 `拒绝访问` 直接退出。
4. 对着下面清单逐条看截图，中了哪条改哪条。
5. 重跑体检 + 重截图，直到每条都过。
6. 交差：前后截图 + 数字对比 + 改了哪几条。

## 清单

| # | 条目 | 谁查 | 本项目怎么做 |
|---|---|---|---|
| 1 | **删除测试** | 人 | 每个标签、每行说明小字、每个装饰，删掉会不会少信息？不会就删。标题上方与标题重复的小眉标直接删。 |
| 2 | **字号** | 脚本+人 | 单页 ≤4 档，最小 12px。实测 30 种、3 处 <12px（`.gui-card-multi` `.thumb-badge` `.old-tile-count`）。归并到 `DESIGN.md` 的 6 档刻度，一次只归并一段（先 14px 附近那一堆）。 |
| 3 | **圆角** | 脚本+人 | 只留 `--radius`(10) / 8px / 999px。嵌套内层 = 外层 − 内边距。`DESIGN.md` 有换算例子。 |
| 4 | **颜色** | 脚本+人 | 新颜色必须进 `:root` 且浅深两套同时写。`:root` 之外现有 39 处硬编码 hex。`--accent` 只给链接和当页主按钮，次要操作用 `.btn-ghost`。 |
| 5 | **渐变与发光** | 脚本 | 现状 0 条渐变、0 处毛玻璃、0 个装饰动画。保持。`0 0 0 3px` 的焦点环是可达性，不算。 |
| 6 | **图标** | 人 | 项目没有图标库。正文 emoji 只有 2 处 `🖼`（`guitu/add-gui.html`、`guitu/provide-tip.html` 的上传区），换成一整套图标库的 SVG 或删掉，不手画。要引入就整套统一，先问用户选哪套。`← 返回` 12 处是文字导航，可留。 |
| 7 | **卡片** | 人 | 一层就够，分组先靠空白，空白不够用 `--card` 底色，最后才用分割线。左侧没有状态要表达就不加彩色竖条。 |
| 8 | **文案** | 人 | 按钮写动作；标题直说内容；同一件事只说一遍。 |
| 9 | **动画** | 脚本+人 | 只用于反馈，`.15s` 过渡够用。不加回弹/晃动/漂浮。 |
| 10 | **深色模式** | 人 | 截图前切系统深色再看一遍。只改了浅色值的颜色等于深色下坏掉。 |

判断新套路：AI 味会随模型变（紫蓝渐变+小火箭是一批，奶油底+斜体衬线大标题+`01/02/03` 章节号是另一批）。用户指出一种新套路，就当成清单一条照样查，并把结论写进 `DESIGN.md`。

## 被纠正之后

用户每纠正一次审美（「别用这个颜色」「按钮太大」），在 `DESIGN.md` 第 8 节的表里加一行：日期、意见、定成的做法、原因。同一行能让下个 agent 直接照做，不必再问一遍。

改完 `DESIGN.md` 跑一次校验，确认没带 BOM、没 CRLF：

```
powershell -NoProfile -ExecutionPolicy Bypass -File tools\check.ps1
```

## 不碰的东西

- 不动 JS 逻辑、数据层、`guitu/data/config.js` 的 key；这一步只碰样式与文案。
- 不新增字体、图标库、动画库，除非用户明确选。
- 页脚只写组织名，不出现成员真实姓名。
- 一次改动只归并一类（字号或圆角或颜色），不要把三类混在一次里，否则出问题没法回退。

## 交差格式

```
做了什么：一句话
体检：字号 30→N 种 / 最小 10.56→N px / 圆角 13→N 种 / 硬编码色 39→N 处
截图：<桌面路径>、<手机路径>
没验证到的：哪些、为什么；没有就写「无」
```
