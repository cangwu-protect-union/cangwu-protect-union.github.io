# 引擎能力表、常见缺口与脚本清单（rpg6-character-batch 伴生文件）

完整 DSL 见 `rpg6-battle` 与 `rpg6.0/README.md` 的 op 表；本文件只放「批量加角色时先看什么」。

## op 一览

由 `_local/tools/rpg6-spec.js` 生成，改 op 后跑 `node _local/tools/rpg6-stats.js --write`，不要手改这张表。

<!-- RPG6-STATS:START ops-brief -->
| op | 作用 |
|---|---|
| `breakValue` | 击溃值增减，钳制在 0..上限 |
| `buff` | 四类 Buff |
| `clearMods` | 按来源移除属性修正，`stats` 只清指定属性 |
| `convert` | 配合 beforeDamage 钩子：把这次受击标记为伤害转血上限（不扣血、等量加血上限） |
| `counter` | 计数器增减，供 `{counter}` 读取 |
| `damage` | 造成伤害；默认只加击溃值，`addStun` 才加眩晕值；`healBack` 按造成的伤害给自己回血 |
| `decay` | 把目标身上指定 kind 的 Buff 百分比减 delta，减到 0 移除（我是天才的勇猛逐回合 −20%） |
| `deny` | 否决这次动作，`reason` 显示给玩家 |
| `dice` | 掷骰分支；`times` 连续独立掷 |
| `directLoss` | 强扣：不减免、不加击溃值 |
| `dispel` | 清 Debuff / 清异常状态 / 清带标记的负面修正 / 清击溃值 / 清标记 |
| `dodge` | 把这次受击标记为已闪避 |
| `forceBreak` | 按当前击溃值直接进入击溃，击溃值不足时不生效 |
| `heal` | 回血，受血量上限钳制 |
| `healFull` | 回满血 |
| `if` | 条件分支；`cond` 支持 gender/status/effect/summon/summonCount/left+op+right |
| `interrupt` | 打断带 `tag` 的持续效果 |
| `mark` | 标记层数增减，`mode:"set"` 直接赋值；delta 支持数值表达式 |
| `markClear` | 清空标记，不写 `key` 就清该单位全部标记 |
| `maxHp` | 血上限增减，常驻修正 |
| `maxMp` | 蓝上限增减，常驻修正 |
| `mp` | 蓝增减，钳制在 0..蓝上限 |
| `note` | 只产出日志，不改变状态；用于「无法打断」这类声明的落点 |
| `reflect` | 蓄力期间的伤害反射（江雨轩） |
| `removeEffect` | 按 key 移除持续效果，并把 `untilRecast` 标记为该 key 的属性修正一并回滚（剃发为僧复原） |
| `roll` | 掷骰并存进计数器，供 `{counter}` 读取 |
| `schedule` | 延迟结算；`after` 是几个标准回合后 |
| `setBasicMod` | 改这次普攻：类型、倍率、段数、回血、无击溃、哑火 |
| `setBasicMode` | 把普攻改成给召唤物回血 |
| `shield` | 护盾：独立血量池，伤害全额吸收；标准回合末计时，到期执行 `onExpire`（杨冬明坚若磐石） |
| `stat` | 面板修改，进 `mods`；`restore` 让 set 归零后逐标准回合恢复原值 |
| `status` | 状态，按标准回合计时 |
| `strike` | 立刻执行一次普攻 |
| `stunValue` | 眩晕值增减，钳制在 0..上限 |
| `summon` | 生成召唤物，`key` 指向 `summons` 定义 |
| `taunt` | 嘲讽值增减 |
| `tick` | 逐标准回合重复执行的持续效果（DoT、回蓝、属性）；`gate` 是持有者行动前掷骰跳过行动，`period` 是每 N 个标准回合结算一次，`breakOnSourceStatus` 是来源被击晕/击溃即结束，`breakOnHolderStatus` 是持有者进入指定状态即结束；`guard` 是防护层（取消 N 次伤害 + onCancel ops），`immune`/`breakImmune`/`chargeGuard` 是防护声明 |
| `use` | 内联执行另一个技能的 ops |

## 常见缺口（分诊会标出来，逐条确认能否用现有组合近似）

- 复活/免死、状态快照或回到第 N 回合、每回合额外行动
- 依赖场外行为的判定（喊数字、对方回答）、需要对方逐回合输入的交互
- 按次数反弹；需要关闭已挂持续效果的入口（「可停止」）
- 公式里读「本次伤害值」的表达式（`evalValue` 没有 `amount`）

护盾、免击溃/免异常/蓄力不断、法伤专属易伤、伤害转血上限、群攻上限、`{summonCount}`、额外动作、`untilRecast` 已在第六/七批落地，见上面的 op 表。

## 计划文件与脚本

| 路径 | 用途 |
|---|---|
| `assets/plan.template.json` | 空计划模板（含 fixture 命名规则） |
| `assets/plan.example.json` | 真实候选示例（不写入游戏，只演示 schema） |
| `scripts/lib.mjs` | 读 seed 与技能库、覆盖率计数、`eachOp` 递归找 summon.key |
| `scripts/inventory.mjs` | 盘点：`--remaining`、`--character`、`--json` |
| `scripts/triage.mjs` | 缺口分诊：`--remaining`、`--character`、`--json` |
| `scripts/plan.mjs` | `--check` 校验、`--table` 出逐技能确认表、`--scaffold --write` 直接落盘；op/hook 名单从引擎现扫 |
| `scripts/verify.ps1` | 一条命令验收：plan → 引擎单测 → 冒烟 → `check.ps1`；`-Browser` 才跑浏览器组 |

`plan.mjs --write` 会改 `data/skills/*.js` 与 `index.js`（按四行 `RPG6-SCAFFOLD` 锚点插入），另外写 `_local` 里的机制文档骨架与文档计数；其余脚本只读源码。
