# 策略实验室 · 使用说明

## 这是什么

一个本地跑的程序。它让引擎自己打自己：给每对角色练出一个策略库（条件规则打法 + 混合均衡），两两组合打很多局，统计胜率矩阵，用均衡判定每对角色属于静止、封闭还是开放。不需要开网页，不需要登录。

## 现在能跑到什么程度

完整流水线（2026-11 五轮迭代后）：

- 策略 = 条件规则表：默认权重 + 至多 4 条「8 特征条件→权重」规则（双方血量档、嘲讽、蓝量、回合、对方上一步、召唤物、击溃值临界），进化搜索，可读成中文规则。
- 训练 = 双 oracle 循环（PSRO-lite）：双方轮流对「当前均衡混合」进化最佳回应，按可榨取值（exploitability）收敛；每对跑 3 个训练种子合并策略池，修剪到每侧 8 套。
- 判定 = 混合均衡：极差近零 → 纯鞍点 → 支撑枚举求混合均衡；封闭按深度分记强/中/弱；每格 Wilson 区间重判做灵敏性标注。
- 报告带深度分、均衡值、可榨取值、被支配打法、灵敏性；留出验证用「最优打法 vs 对手在其它配对练出的策略池」。

## 怎么跑

在工作区根目录执行：

```
node rpg6.0/strategy-lab/lab.mjs --chars=5
```

跑完在 `_local/strategy-lab/runs/<时间戳>/` 里出三份东西（产物不进仓库，不会被 check.ps1 扫）：

| 文件 | 看什么 |
| :--- | :--- |
| `report.html` | 双击打开，热力图 + 每对明细，可筛选状态 |
| `report.md` | 纯文本版，适合贴到别处 |
| `policies.json` | 全部打法、规则、训练轨迹、均衡混合 |

6 角色 15 对约 3.5 分钟。只跑一对：

```
node rpg6.0/strategy-lab/lab.mjs --pairs=王荣逸+李硕 --games=400
```

先自检，确认引擎接入和判定器没问题：

```
node rpg6.0/strategy-lab/selftest.mjs
```

## 参数

| 参数 | 默认 | 含义 |
| :--- | :--- | :--- |
| `--chars=5` | 5 | 取前几个角色参加（对数按平方涨） |
| `--roster=a,b,c` | 空 | 指定参加的角色 |
| `--pairs=A+B,C+D` | 空 | 只跑指定对，`+` 连接两个角色名 |
| `--strategies=4` | 4 | 每侧初始策略数（训练里会扩张） |
| `--oracles=6` | 6 | 双 oracle 循环迭代上限 |
| `--gens=5` | 5 | 最佳回应进化的代数 |
| `--pop=10` | 10 | 最佳回应进化的候选数 |
| `--eps=0.02` | 0.02 | 可榨取值收敛阈值 |
| `--games=400` | 400 | 终局矩阵每格最多多少局 |
| `--mingames=40` | 40 | 自适应采样的最少局数；全一边倒就提前收手 |
| `--noadaptive` | 关 | 关掉早停，每格打满 `--games` |
| `--screen=6` | 6 | 第一段评估每格多少局 |
| `--confirm=12` | 12 | 第二段评估每格多少局 |
| `--cap=400` | 400 | 单局步数上限，超了算平 |
| `--seed=1000` | 1000 | 种子基准（每个训练种子在此基础上 +1000） |
| `--out=xxx` | `_local/strategy-lab/runs/<时间戳>` | 产物目录，相对工作区根 |
| `--recalibrate` | 关 | 强制重建技能标定表 |

## 输出怎么读

总表长这样：

| 对局 | 状态 | 平均胜率 | 平局率 | 强度 | 稳定性 | 极差 | 深度分 | 最优 vs 别处打法池 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 王荣逸 vs 江雨轩 | 封闭（强） | 50.0% | 0.0% | 强 | 稳定 | 1 | 0.5 | 100% / 90% |
| 王荣逸 vs 王泺然 | 静止（无策略差异） | 0.0% | 0.0% | — | 稳定 | 0 | 0 | 0% / 100% |

- **平均胜率**：左边角色在矩阵所有格子的平均胜率。
- **平局率**：到步数上限没分胜负的比例。
- **极差**：矩阵里最高胜率减最低胜率。极差 0 就是"换打法结果不变"。
- **深度分**：均衡面前纯策略打法的可榨取值，0–1；只有混合均衡才有深度。
- **最优 vs 别处打法池**：双方最优打法对这个对手在其它配对里练出的策略池的胜率，泛化检验。
- **强度**：静止 = 换打法能拉开多少（≥0.25 记强）；封闭 = 深度分（≥0.25 强、≥0.10 中、否则弱）。
- **稳定性**：样本对半分，两半分别判一次，一致才算稳定。
- 明细行还有：均衡值、被支配打法、灵敏性（Wilson 区间内结论是否翻转）、训练种子数与收敛原因、可榨取值。

每对后面有一张明细矩阵，鞍点标 ★；封闭对没有鞍点，报告会列出均衡支撑的打法与混合比例。

## 状态怎么理解

| 状态 | 子类 | 含义 | 设计含义 |
| :--- | :--- | :--- | :--- |
| 静止 | 唯一最优 | 有一套打法压住对手所有选择，换别的会掉 | 死局，选人即定胜负 |
| 静止 | 多重最优 | 有几套并列最强，其余明显更差 | 有最优解，但不止一个入口 |
| 静止 | 无策略差异 | 任何打法都改不了胜负，一边倒 | 死局，纯粹角色强度 |
| 封闭 | 强/中/弱 | 无鞍点，双方都要按混合比例换打法互相克制 | 猜拳结构，通常最耐玩 |
| 开放 | 平坦 | 所有格子挤在 50% 附近 | 策略维度不出信息 |
| 开放 | 弱鞍点 | 有最优打法，但换招只值几个百分点 | 最优解存在但不值得算 |
| 开放 | 单向 | 只有一方的选择能改变结果 | 另一方是"陪打"，深度不对称 |

另外有两个标记：`预算不足`（前后两半种子判出的结论不一致，样本不够）；灵敏性翻转（Wilson 区间端点重判结论变了，此时结论对抽样敏感）。

## 常见问题

**封闭（强）是什么样的？**
王荣逸 vs 江雨轩：双方各练出 8 套打法后，矩阵无鞍点，均衡是双方各按 50/50 混合两套打法（王荣逸混用省消耗流与攒资源流，江雨轩混用第 3 回合起伤害流与补刀流），任何一方改用单一打法都会被对方克制。深度分 0.5。

**为什么有的对局只打了 40 局？**
自适应采样：打到 40 局如果全是一边倒，就提前收手，标"确定性"。注意：引擎先手顺序有随机性（种子决定），"确定性"只对采样过的种子窗口成立，灵敏性标注是兜底。

**结论和我想的不一样。**
先看"最优 vs 别处打法池"列：一侧接近 0% 说明该侧训练把打法练废了。再看可榨取值：0 说明搜索认为没有更优回应；大于 0（如骰子噪声对）说明没收敛，结论要打折。最后看灵敏性是否翻转。

**能改角色数值吗？**
不能。这个工具只读引擎数据。要平衡角色先改 `battle-skills.js`，再重跑。

## 边界

- 结论只对本次训练出的策略库成立，换策略库结论会变。
- 最佳回应是进化搜索，可能局部最优；"可榨取值 0"只对搜索能力成立。
- 只看单挑，三方克制循环测不出来。
- 判定先看极差近零（0.05）、再看纯鞍点、最后混合均衡；极差近零时不会判成"有最优打法"。
