## 14. 命令行

```
node rpg6.0/strategy-lab/lab.mjs --chars=5
node rpg6.0/strategy-lab/lab.mjs --roster=王荣逸,刘文哲,江雨轩,于梓越,李硕,王泺然
node rpg6.0/strategy-lab/lab.mjs --pairs=王荣逸+李硕 --games=400
node rpg6.0/strategy-lab/lab.mjs --chars=5 --oracles=3 --gens=3
node rpg6.0/strategy-lab/lab.mjs --stage=calibrate
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--chars` | `5` | 取前 N 个角色，或 `--roster=a,b,c` 指定 |
| `--pairs` | 空 | 只跑指定对，`+` 连接，逗号分隔多对 |
| `--games` | `400` | 终局矩阵每格最多多少局 |
| `--mingames` | `40` | 自适应采样的最少局数 |
| `--noadaptive` | 关 | 关掉早停，每格打满 `--games` |
| `--strategies` | `4` | 每侧初始策略数 |
| `--oracles` | `6` | 双 oracle 循环迭代上限 |
| `--eps` | `0.02` | 可榨取值收敛阈值 |
| `--gens` | `5` | 最佳回应进化代数 |
| `--pop` | `10` | 最佳回应进化候选数 |
| `--screen` | `6` | 第一段评估局数 |
| `--confirm` | `12` | 第二段评估局数 |
| `--cap` | `400` | 单局步数上限 |
| `--seed` | `1000` | 种子基准（3 个训练种子在此之上 +1000） |
| `--out` | `runs/<时间戳>` | 产物目录 |
| `--recalibrate` | 关 | 强制重建技能标定表 |

## 15. 输出

```
_local/strategy-lab/runs/<runId>/
  report.md          人读的汇总报告
  report.html        单文件热力图，双击即开，无外部依赖
  run.json           完整数据（矩阵、策略池、均衡混合、灵敏性）
  verdicts.json      每对的状态与证据
  policies.json      全部策略（规则、可读翻译、训练轨迹、均衡混合）
```

产物放 `_local` 下：不进仓库，也不会被 `check.ps1` 的文件扫描算进去。

`verdicts.json` 一项：

```json
{
  "pair": ["王荣逸", "江雨轩"],
  "state": "封闭",
  "strength": "强",
  "resolve": "solid",
  "stable": true,
  "avgWinA": 0.50,
  "drawRate": 0.0,
  "spread": 1,
  "depth": 0.5,
  "value": 0.5,
  "support": [2, 2],
  "sensitive": { "lo": ["封闭", "封闭"], "hi": ["封闭", "封闭"], "stable": true },
  "meta": { "seeds": 3, "iterations": 3, "exploitability": 0, "stopReasons": ["converged", "converged", "converged"] }
}
```

`report.md` 内容顺序：

1. 一句话结论：几对静止、几对封闭、几对开放。
2. 总表：每对一行，状态、平均胜率、平局率、强度、稳定性、极差、深度分、留出验证。
3. 明细：每对的矩阵（标出鞍点）、均衡值、被支配打法、灵敏性、可榨取值、收敛原因。
4. 策略清单：每角色每对手的最优策略，翻译成规则句子。
5. 盲区声明：结论只对本策略库成立；单挑看不到三方循环。

## 20. 演进记录（2026-11 五轮迭代）

| 轮 | 内容 | 关键发现 |
|---|---|---|
| R1 | 判定器重写：支撑枚举混合均衡、深度分、支配检测、新口径；回归集 8 例 | 旧口径把弱猜拳 [[0.55,0.45],[0.45,0.55]] 误判平坦；旧 10 对数据全是 0/1 退化矩阵，新旧口径一致（零回归） |
| R2 | 条件规则 DSL（8 特征、5 变异算子 + 交叉、可读翻译、legacy 兼容） | 交替训练不稳定实锤：3 对结论翻转中 2 对是 DSL 找到真打法，1 对是训练噪声（交叉对打定位） |
| R3 | 双 oracle 循环（PSRO-lite）：均衡混合→最佳回应→exploitability 收敛 | 抓到并修复 solveMixed 支撑外校验方向写反的真 bug（非对称矩阵才现形）；BR 预算不够会假收敛（pop 10×5 代 + 现任种子修复） |
| R4 | 3 种子合并策略池 + 修剪 + Wilson 灵敏性 | 王荣逸×江雨轩出现第一个真实封闭（强）结构，深度分 0.5、双方 50/50 混合，单种子跑不出来；修复混合均衡支撑相对数组展开 bug |
| R5 | 口径定稿、文档与 skill 更新、验收 | — |

经验：

1. 判定口径按「极差近零 → 纯鞍点 → 混合均衡」的顺序，阈值 0.05/0.10/0.25 与深度分 0.10/0.25 是当前定稿值，改前读 使用说明.md。
2. 均衡求解器的两个支撑外不等式方向是最高危的静默错误源，回归用例必须有非对称、带支撑外策略的矩阵。
3. 「可榨取值 0」只对 BR 搜索能力成立；单种子结论是策略库相对的，合并多种子才稳。
4. 引擎先手顺序随种子变化，「certain」标记只覆盖采样过的种子窗口。
