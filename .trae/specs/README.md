# spec 目录约定

每条活跃线一个目录，目录名用 ASCII，下面固定三个文件：

```
.trae/specs/
├── battle/          # 对局线：认输/终局、规则页、卡死审计、陌生人入口
│   ├── spec.md
│   ├── tasks.md
│   └── checklist.md
├── chars/           # 角色线：剩 4 人 17 技能
└── _template/       # 模板，不是真 spec
```

- 用 Trae 的 `/Spec` 生成时，落盘位置和文件名正好是这个结构，不需要再搬。
- 手写就复制 `_template/` 整个目录改名。
- `tasks.md` 是唯一的任务来源。任务卡没写"允许改的路径 + 验收命令"就不算写完。
- 卡片状态只有四个：待做 / 在做 / 待验 / 已验。`已验` 只由 adversary 判定通过后由主 Agent 改。
- 冻结面（主站、guitu、quyu、suggest、角色档案）不进 spec；出现阻塞错误时开一张单独的卡，卡里写清"只修阻塞"，不进本目录也可以。
