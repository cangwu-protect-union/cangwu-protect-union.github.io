# CPU及回合制游戏工作室联合组织 · 官方网站

苍梧的保护者结成的联盟，对抗鬼的最前线。

本仓库是这个组织的公开门户网站，用原生 HTML + CSS 手写，没有框架、没有构建步骤。

划分原则很简单：**能公开的按模块放，不能公开的统一进 `_local/`**。
根目录只留主站三页、共用样式和生成的模块文档，每个功能开一个目录，打开文件夹一眼就能看出结构。

**站点建议**（`suggest/`）：项目页第一个卡片上的「提供建议 / 审核建议」。访客匿名提交，数据进 CloudBase 的
`site_suggestions` 表；匿名只能插入，读取与删除要组织验证令牌。限频由数据库触发器做：
全站每分钟 20 条、相同内容 10 分钟内重复直接拒绝，再按 `x-forwarded-for` 做每 IP 每分钟 3 条
的尽力而为（实测网关转发过来的 IP 每次可能不同，这一条不保证生效）。
两个页面直接引用 `guitu/data/config.js` 与 `guitu/js/gui-gate.js`，不另存副本。

**纯静态**——没有后端、没有数据库服务需要自己跑、不需要编译。
鬼图鉴的数据存在腾讯云 CloudBase（PostgreSQL），页面本身仍是纯静态。

本地预览请用静态服务器（直接用 `file://` 打开会导致图鉴功能受限）：

```bash
python -m http.server 8000
# 主站      http://localhost:8000/
# 鬼图鉴    http://localhost:8000/guitu/guitu.html
```

## 修改约定

如果你想参与维护这个网站，请遵守以下约定：

1. **编码必须是无 BOM 的 UTF-8**。项目含大量中文，编码一旦变成 ANSI/GBK，全站乱码。
2. **换行符用 LF**。`.gitattributes` 和 `.vscode/settings.json` 已做好强制约束。
3. **一个中文字段不要跨行书写**。HTML 会把源码里的换行压缩成一个空格，中文句子中间会多出空格。
4. **不要提交真实联系方式**。所有成员一律使用代号，联系方式通过 `mailto:` 之外的渠道私下传递。
5. **提交前先看 `git status`**。避免把 Office 临时锁文件（`~$xxx.md`）、`.preview/` 截图误提交。

## 容易踩的坑

这些坑都散在多个脚本里，暂时没法做成自动检查，先记在这儿；数据源那一条已经有测试
（`_local/tests` 的「数据源 · 兜底」组）。改之前对照一眼，能省一次返工。

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 列表里同一条出现两份 | 云端读成功后又合并了 `gui-entries.js` 的种子 | 种子只在 `list()` 的兜底分支合并；跑数据源测试 |
| 区域页查询 400，报列不存在 | 鬼详情页加载 `guitu/data/config.js`，`GUI_CLOUDBASE.table` 是 `gui_entries` | 区域表名只从 `ZONE_APP.table` 取 |
| 验证题改了，另一个模块还是旧题 | `gui-gate.js` 在 `guitu/` 和 `quyu/` 各有一份副本 | 两边各改一次；答案只存数据库 `gui_secrets` |
| 导航改了只有部分页面生效 | 页头是逐页复制的，共 43 个 HTML | 全局搜 `关于` 的链接批量改，再跑 `_local/tests` 导航组 |
| 删了关联，对方页面还显示 | `related` 单向存储、双向显示 | 用 `relation-utils.js` 的删除逻辑，它会先把对方归档成版本 |
| 条目位置偏几百米 | 库里存 WGS-84，高德底图要 GCJ-02 | 只在渲染层转换，别把 GCJ-02 写回数据库 |
| 本地地图全灰，控制台 403 / `ERR_BLOCKED_BY_ORB` | 天地图 key 绑了部署域名白名单 | 用 `127.0.0.1` 并带部署域名 Referer，或直接线上验证 |
| 加了字段，表单和列表有一边不认 | 字段定义没有走单点 | 只改 `ENTRY_FIELDS` / `ZONE_FIELDS`，再加表单、`mapRow` / `toRow` 与数据库列 |
| 中文句子中间多出空格 | HTML 里一句话跨了行 | 一个中文字段写成一行 |
| 传 iPhone 原图很慢或失败 | 浏览器端压缩 + HEIC 转码，HEIC 库 1.3 MB 按需加载 | 别改成 CDN，也别预加载 |
| `build-docs.js --check` 报「文档已过期」 | 改了页面、脚本或跨模块引用 | 跑 `node _local/tools/build-docs.js`；这是拦截，不是脚本坏了 |
| 生成 PNG 时卡住不动 | 无头 Edge 在受限终端里起不来 | 换普通终端跑；四份 md 已经写好，PNG 只是配图 |

各模块的细节以 `guitu/README.md`、`quyu/README.md` 和两份 `架构.md` 的第四、五节为准。

## 配色与样式

全站配色集中在 `css/style.css` 顶部的 `:root` 变量里：

```css
:root {
  --bg:        #ffffff;   /* 背景色 */
  --fg:        #1f2328;   /* 正文颜色 */
  --accent:    #0969da;   /* 强调色 */
  --max-width: 760px;     /* 正文最大宽度 */
}
```

改这一处，所有页面同时生效。深色模式在 `@media (prefers-color-scheme: dark)` 里自动适配，
窄屏适配在文件末尾的 `@media (max-width: 560px)` 里。
