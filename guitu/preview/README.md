# 鬼图鉴 · 预览图

开发过程中的界面截图与架构图，按文件名可搜索。

架构图的矢量版本见 [../架构.md](../架构.md)，这里只是渲染好的 PNG。

重新生成架构图：

```
node _local/tools/gen-arch-diagram.js
node _local/tools/render-diagram.js
```
